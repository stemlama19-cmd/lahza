# Adhan user flow, 2026-10-04
Capture text or browser speech transcription → classify intention → ask confirmation for ambiguous sound → retrieve ranked evidence from versioned trusted corpus → generate bounded paraphrase from evidence claims → verify source, claim, citation, scope and generalisation → Pass / repair once / Stop → display cited answer → choose 10s / 30s / 2min / explore / handoff packet.
No acoustic adhan classifier is claimed. Speech recognition is question dictation, optional browser feature, and can involve the browser vendor. No recording stored by LAHZA.
Low confidence: describe sound and confirm, never identify an unheard sound.
Insufficient evidence: stop with explanation. Outside scope: stop. Specialized rulings/differences: specialist. Local customs: cultural ambassador. In-scope explanation: trained knowledge volunteer.
Handoff: local downloadable packet, no connected service yet; no fake queue or live volunteer.
